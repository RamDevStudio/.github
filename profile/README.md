## 👋 About the Studio

**RamDevStudio** is an independent studio working where real-time graphics meet machine learning. We ship:

- 🥽 **XR & rendering tech** for Unity URP — built for standalone VR performance budgets.
- 🧠 **AI systems** that run where people are — offline voice assistants, healthcare automation, and LLM pipeline diagnostics.
- ⚡ **Lean developer tools** — zero-fuss CLIs published on PyPI that solve one problem well.
