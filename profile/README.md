## 🎮 Unity

Rendering and XR tech for Unity URP, built to fit standalone VR performance budgets.

- **[URP-Volumetric-Fog](https://github.com/ramalingamthangamani/URP-Volumetric-Fog)**: Raymarched volumetric fog and light shafts for Unity 6 / URP 17, built on the RenderGraph API with XR single-pass rendering in mind. Tuned for Meta Quest standalone and Quest Link, and installable as a UPM Git package.

## 🧠 AI

Applied AI across voice, vision, healthcare, and LLM operations.

- **[Nanban](https://github.com/ramalingamthangamani/Nanban)**: An offline voice companion for Windows. Understands English, Tanglish, and Tamil, runs fully on-device, and controls apps, files, and the system hands-free.
- **[Agentic-System-Performance-Analyzer](https://github.com/ramalingamthangamani/Agentic-System-Performance-Analyzer)**: A diagnostic platform that inspects API latency, prompt efficiency, and computational bottlenecks in LLM and agentic pipelines.
- **[AI-Prescription-Parser-Auto-Registration-Suite](https://github.com/ramalingamthangamani/AI-Prescription-Parser-Auto-Registration-Suite)**: Turns handwritten and digital medical prescriptions into structured health records using OCR and NLP.
- **[Sign-Language-Embedding-Toolkit](https://github.com/ramalingamthangamani/Sign-Language-Embedding-Toolkit)**: Extracts, normalizes, and learns embeddings from sign language video using pose estimation.
- **[Social-Radar](https://github.com/ramalingamthangamani/Social-Radar)**: A full-stack social intelligence dashboard for trend detection and sentiment scoring across Reddit and YouTube.
- **[medical-assistant-for-interview](https://github.com/ramalingamthangamani/medical-assistant-for-interview)**: A medical assistant that answers a wide range of health questions in one conversational experience.

## 🛠️ Developer Tools

Small, dependable tools that install in seconds and stay out of your way.

- **[Aistrap](https://github.com/ramalingamthangamani/Aistrap)**: Generates clean, ready-to-run AI/ML project structures from ten templates, including RAG, FastAPI, agents, and MCP servers. `pip install aistrap`
- **[PortInspector](https://github.com/ramalingamthangamani/PortInspector)**: A zero-dependency, cross-platform CLI for inspecting local ports, finding owning processes, scanning ranges, and watching for changes. `pip install portinspector`
- **[mindsetwithram-auto-reels](https://github.com/ramalingamthangamani/mindsetwithram-auto-reels)**: Scheduled Instagram Reels publishing with GitHub Actions, Cloudinary, and the Instagram Graph API.

## 👋 Getting involved

Ideas, bug reports, and pull requests are welcome on every project. Open an issue on the relevant repository to report a problem or propose a feature, or start a pull request if you'd like to contribute directly. We're happy to collaborate on XR, AI, and developer tooling.

## 👾 Reporting security issues

If you find a security vulnerability, please don't open a public issue. Contact the maintainers privately so it can be fixed before details are shared.
